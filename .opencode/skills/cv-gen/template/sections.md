# Sections Template
Use this type of Markdown template to keep track of user's choices and compiled sections

```md
---
full-name: <the user's first name and second name>
place-of-birth: <the user's place of birth with country, city and province>
contacts:
  phone-number: <the user's phone number>
  email-address: <the user's email address>
socials: <list of the social network profiles of the user>
personal-website: <link to the user's personal website>
---

# Presentation
<a presentation letter personalized for the specific employer's job description and informations>

# Work Experiences
<the list of work experiences of the user with a brief description of how they are relevant for the job>

# Education
<the list of titles and certifications obtained by the user>

# Skills
## Languages
<the list of known languages for the user with their relative level>

## Technical
<set of specific, technical skills required for the job, that the user actually possesses>

## Soft
<set of soft, cross-domain skills that the user actually possesses>
```
